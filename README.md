# 词间 CIJIAN · IELTS

一个使用原生 JavaScript、HTML 和 CSS 的词汇学习网站。支持章节词库、每日计划、拼写练习、释义回忆与听音练习；复习内核使用真正的 FSRS-6，学习数据保存在当前浏览器。

项目自有代码采用 [MIT 许可证](LICENSE)。第三方代码的许可证分别保留，详见 [第三方声明](THIRD_PARTY_NOTICES.md)。仓库包含 54 条自编示例词汇，覆盖 22 个主题，不包含授权未明确的第三方完整词表或原书音频。

## 运行

需要 Node.js 20 或更高版本。

```sh
git clone https://github.com/Taccat-00/cijian-ielts.git
cd cijian-ielts
npm ci --ignore-scripts
npm start
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。PowerShell 如遇执行策略限制，使用 `npm.cmd` 代替 `npm`。端口占用时可用 `npm start -- --port 4174`，此时浏览器记录也属于新的来源。

```sh
npm test
npm run build
node scripts/serve.mjs --dist --port 4176
```

`dist/` 是可部署到静态托管服务的产物，所有资源均为相对路径。没有后端、运行时 CDN 或运行时第三方调度服务。不应直接双击 `index.html`。本次开源不自动部署网站。

## 功能

- 按章节浏览、搜索，支持单章或多章练习。
- 每日计划优先选取到期复习，再补足所选章节的新词，支持顺序和随机模式。
- 看中文写英文、看英文想中文、听音拼写，以及混合题型。
- 生词本、独立错题记录、发音、单词详情和个人笔记。
- 暂停、刷新恢复、计时、每日去重统计与稳定的当天计划。
- 响应式界面、键盘操作和减少动态效果支持。

## FSRS 与兼容

固定使用 `ts-fsrs 5.2.3`（FSRS-6），默认权重、0.90 保持率，无个人参数训练。采用库支持的 `enable_short_term:false`，与现有按天任务衔接，不覆盖库返回的到期时间。

拼写/听写错误映射 Again，正确映射 Good；现有回忆自评错误、模糊、正确分别映射 Again、Hard、Good。相同题位重复提交不会重复计分、调度或写日志。错题本的加入与移除规则独立于 FSRS。

旧日程和学习身份在升级时保留，历史不足时不伪造或回放评分，下一次真实复习才开始建立 FSRS 状态。详见 [FSRS 与数据说明](docs/FSRS.md)。

`src/vendor/ts-fsrs-5.2.3.js` 和许可证是官方 npm 包的原样副本，随静态网站分发；测试对照锁定版本的 npm 包核对状态、日志和文件内容。

## 数据与隐私

记录在当前来源的 localStorage 中，不上传服务器。无账号、跨设备同步或云数据库。域名、协议、端口和浏览器配置变化会对应不同的存储，清理站点数据会丢失该来源的学习记录。写入使用 Web Locks；不支持安全写入锁的环境只读。

仓库不包含任何个人学习记录、笔记、备份、凭据或私人仓库历史。测试夹具为合成数据。

示例词库是自编学习材料，不宣称完整覆盖雅思词汇，也不保证与任何出版物一致。拥有合法使用权的个人词库可放在 `data/vocabulary.local.json`，文件格式须通过 `src/data.js` 的校验；该文件被 Git 忽略，默认静态构建也不包含它。词条 ID 影响历史记录关联，应保持稳定。

浏览器发音使用 SpeechSynthesis，优先选择英语声音；不是原书录音，实际可用性取决于浏览器和系统。
