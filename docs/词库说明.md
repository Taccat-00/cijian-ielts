# 完整词库与来源

## 默认内容

本仓库默认使用 `data/vocabulary.json`：22 个章节、3631 个去重词条。开发服务和 `npm run build` 生成的静态产物都包含并加载这份完整文件，不要求部署者自行补入词库。

该文件与项目现有本地完整学习词库一致，保留原词条 ID、章节归属、拼写变体、释义、例句与补充字段。跨章节可能出现同一词条，章节词数之和不等于去重词数。词条 ID 用于关联学习记录，不宜随意更换。

`data/demo.json` 的 54 条自编示例只用于默认文件缺失、损坏时的回退，以及自动化测试。

## 质量与局限

词表尚未逐词校订，不宣称与纸质书完整对应。3631 个词条中有 3627 条英文例句、41 个独立音标字段、41 条例句中文翻译和 6 条自编记忆线索；未覆盖部分按原页面规则显示，不补造内容。

发音使用浏览器 SpeechSynthesis，不是原书录音。完整词库来自既有项目数据，本次只改变开源版本的默认加载和构建包含范围，不改变题型、评分、FSRS 或错题收录规则。
